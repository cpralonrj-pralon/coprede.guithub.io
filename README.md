# 📖 Guia do Operador XPT / XPERTrak

Uma aplicação web responsiva, interativa e independente para consulta rápida operacional por atendentes e operadores de teleatendimento do sistema **XPT / XPERTrak** e diagnóstico de qualidade de experiência (**QoE**).

---

## 🌟 Destaques e Funcionalidades

- 🔍 **Busca em Tempo Real**: Digite palavras-chave (com atalho `/`) com destaque instantâneo de ocorrências no texto e contadores por seção.
- 🌓 **Modo Claro / Escuro**: Suporte a preferências de sistema e alternância manual de tema com cores harmoniosas e acessíveis.
- 📱 **Design Responsivo & Mobile First**: Layout adaptável com menu gaveta em telas menores e visualização em coluna única otimizada em desktops.
- ⚡ **Desempenho Elevado**: Arquivos estáticos sem dependências pesadas externas, carregamento ultrarrápido diretamente no navegador.
- 📋 **Tabelas & Checklist de Procedimentos**: Passo a passo interativo para atendimento, semáforo de métricas (SNR, TX, T3/T4, Flaps) e direcionamento correto de acionamento por equipe.

---

## 🚀 Como Executar Localmente

Não é necessário instalar Node.js, servidores de aplicação ou gerenciadores de pacotes.

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/cpralonrj-pralon/coprede.guithub.io.git
   ```
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).

---

## 🌐 Como Publicar no GitHub Pages

Para disponibilizar o guia online gratuitamente via **GitHub Pages**:

1. Acesse o seu repositório no GitHub.
2. Vá em **Settings** > **Pages** (no menu lateral esquerdo).
3. Em **Build and deployment** > **Source**, selecione `Deploy from a branch`.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.
6. Em instantes, o site estará acessível no link fornecido pelo GitHub (ex: `https://cpralonrj-pralon.github.io/coprede.guithub.io/`).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica corrigida e acessível.
- **CSS3 (Vanilla)**: Design moderno com CSS Variables, suporte nativo a `prefers-color-scheme`, layout em CSS Grid & Flexbox.
- **JavaScript (ES6)**: Normalização de texto por expressões regulares Unicode, manipulação dinâmica do DOM, atalhos de teclado e busca textual otimizada.
